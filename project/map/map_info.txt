
SETTINGS
└ spawnrate : 차량이 스폰하는 비율을 정합니다 (0~1 사이)

NODE
├ <부호> <번호> <x좌표,y좌표>
├ N : 기능이 없는 점입니다
├ S : 차량이 스폰하는 지점입니다
└ T : 신호등 기능을 하는 점입니다

LINK
├ <부호> <번호> <시작노드 번호,끝노드 번호>
└ L : 시작노드에서 끝노드를 잇는 선입니다. 순서가 중요합니다.

PATH
├ <부호> <번호> <선1 번호,선2 번호,선3 번호 ...>
└ P : 선으로 구성된 하나의 경로입니다. 차량은 이 경로를 따라가게 될 것입니다

ETC
├ 띄어쓰기로 구분됩니다. ex) "N 1 500,500", "P 1 1,2,3,4"
├ 번호는 반드시 번호순으로 부여할 필요가 없습니다
└ 교차로에 신호등이 반드시 필요하지 않습니다.
